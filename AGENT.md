# AGENT.md

This is the **main entry point** for MCA III Semester mini-project documentation guidance.

Use **progressive disclosure**:

- Start with this file for quick rules and workflow.
- Open subfiles only when deeper detail is needed.

## Quick Rules (Must Follow)

- Universal template only (independent of project domain/architecture).
- Softcopy submission.
- Minimum 30 pages.
- Keep formatting, numbering, and chapter order compliant.
- Do not invent screenshots, logs, or test evidence.

## Purpose of This project

- Iterating a project for MCA III Semester mini-projects.
- Generating a project document
- Generating a single mockup folder

## Folder Structure

- `ALLProjects.md` : Contains a list of all projects with their respective numbers. and AI notes from ideation
- `Project<nn>` : Main project folder, where `<nn>` is the project number.
  - `mockup/` : Contains the single mockup folder for the project.
  - `document/` : Contains the generated project document.

## Standard Execution Order

1. Read this file.
2. Apply [01-formatting.md](./claude/01-formatting.md) and [02-front-matter.md](./claude/02-front-matter.md) constraints first.
3. Draft chapters using [03-chapter-structure.md](./claude/03-chapter-structure.md).
