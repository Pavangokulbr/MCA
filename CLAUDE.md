# CLAUDE.md

This is the **main entry point** for MCA III Semester mini-project documentation guidance.

Use **progressive disclosure**:

- Start with this file for quick rules and workflow.
- Open subfiles only when deeper detail is needed.

## Quick Rules (Must Follow)

- Universal template only (independent of project domain/architecture).
- Softcopy submission.
- Minimum 30 pages.
- Keep formatting, numbering, and chapter order compliant.
- Do not invent screenshots, logs, or test evidence.
