# 06 Agent Workflow

Use this process whenever assisting with report creation:

1. Collect project-specific inputs:
   - Domain
   - Objectives
   - Modules
   - Tech stack
   - Real testing evidence
2. Draft section-by-section in the chapter order from [03-chapter-structure.md](./03-chapter-structure.md).
3. Confirm each section with the user before moving to next section.
4. Enforce formatting rules from [01-formatting.md](./01-formatting.md).
5. Enforce front matter/page numbering from [02-front-matter.md](./02-front-matter.md).
6. Validate numbering/figures/tables via [04-numbering-figures-tables.md](./04-numbering-figures-tables.md).
7. Finalize references and appendices using [05-references-appendix.md](./05-references-appendix.md).

## Guardrails

- Keep this guide universal; do not force a specific project architecture.
- Do not invent test logs, screenshots, metrics, or implementation evidence.
- Mark chapter items as Not Applicable only after user confirmation.
