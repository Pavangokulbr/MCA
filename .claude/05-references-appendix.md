# 05 References and Appendix

## Bibliography / References

Preferred format:

- Author Name, Title of book/paper, Publisher/Source, Year.

Rule:

- Arrange bibliography strictly in alphabetical order by author name.

## Appendix Checklist

Appendices may include:

1. User documentation
2. Installation instructions
3. README (how to interact with system)
4. Sample source programs
5. Team member contribution split
6. Glossary
