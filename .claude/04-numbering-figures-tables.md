# 04 Numbering, Figures, and Tables

## Paragraph Numbering

- Use 2.1, 2.2, ... where:
  - first digit = chapter number
  - second digit = paragraph number
- Sub-paragraphs: 1.1.1, 1.1.2, ...
- If institutional rule allows, first paragraph number can be omitted.
- Use bold for headings/subheadings; do not underline.

## Figure/Photo/Table Numbering

- Figure: Fig. 1.1, Fig. 1.2, ...
- Photo: Photo 1.1, Photo 1.2, ...
- Table: Table 1.1, Table 1.2, ...
- First digit = chapter number; second digit = item number.

## Graph Rules

- Graphs must be legible and readable.
- Points used for drawing curves should be clearly indicated.
