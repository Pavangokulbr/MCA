# 02 Front Matter

## Fixed Page Sequence

1. Page One: Title Page (institution format).
2. Page Two: Bonafide Certificate.
3. Page Three: Acknowledgement.
4. Page Four: Table of Contents.
5. Page Five: Abstract (exactly one page, one paragraph).

## Numbering Rules

- No page numbers on first 3 pages (Title, Bonafide, Acknowledgement).
- Front matter uses lowercase Roman numerals (i, ii, iii, iv, ...).
- Main body uses Arabic numerals (1, 2, 3, ...).
